How to use it

Brief the department

Write the spec first. It passes the replication test when a stranger, with only the document, would build what you meant.

2

Commission the guardrails

Five gates — style, behaviour, coverage, forgotten promises, change-size — built by the agent, wired to run without you.

3

Decide whether it's true

Receipts for every check, one spot-check at random, and a written position on what is still good enough.
