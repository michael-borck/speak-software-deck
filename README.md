# The Speak Software Deck

<p align="center">
  <img src="assets/art/banner.png" alt="The Speak Software Deck" width="720">
</p>

Thirty-two cards of code discipline for people who will never hand-write code:
you describe, an agent builds, and you decide whether it's true. Distilled from
*Speak Software: Programming at the Natural-Language Layer*. Free product: no
gate, no capture.

**Live:** https://michael-borck.github.io/speak-software-deck/

**You describe. It builds. You decide whether it's true.**

## The design

One organic size: 32 cards — The Department (5), Speak (5), Verify (5), Guard
(8), Taste (4), Run (5). One card type: why it goes wrong, the move, the line.

## deck/

| File | What it is |
|---|---|
| `speak-deck-32-cards.md` | The deck, markdown. |
| `speak-deck-32-print.html` | Print & cut. 5 A4 pages, 8 cards per sheet. |
| `speak-deck-32-art.html` | Art edition: portrait cards, category vignettes, 6 per A4. |
| `speak-deck-guide.html` | One-page diagnostic. |
| `speak-deck-desk-card.html` | Every card, every line — one A4 pin-up. |
| `fonts/` | Domine, Funnel Sans, Nanum Gothic Coding (SIL OFL). |

Art: `assets/art/` holds the blueprint identity — cover, back, banner and
category illustrations, generated with limn. Prompts and the locked style
prefix are in `assets/art/README.md` and the `.png.json` sidecars.
