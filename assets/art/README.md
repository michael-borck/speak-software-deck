# The Speak Software Deck — Art Assets

**Style decision:** the deck's identity is the blueprint — specifications drawn
before they are built, deep blueprint blue with fine white linework. Every
prompt starts with this canonical prefix:

```
technical blueprint photograph, deep blueprint blue palette with fine white
and cyan linework, drafting instruments on a dark slate table, dramatic side
light, precise clean composition, generous dark negative space, soft film grain
```

Every prompt ends with: `no text, no letters, no words`

Regenerate with `limn generate -s <size> -o <path> "<prefix>, <subject>, no
text, no letters, no words"` (default SwarmUI, juggernautXL_v9). Sidecars
(.png.json) record the exact prompts.
